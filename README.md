# ResoTweak for Windows

Official installer downloads and the signed automatic-update feed for ResoTweak.
Application source code is maintained in a separate private repository.

[Download the latest installer](https://github.com/ResoTweak/ResoTweak-Releases/releases/latest)

Install the Setup executable once. ResoTweak then checks for newer versions in the background and installs verified updates after you close it. Settings and recovery data are retained.

Requires Windows x64, .NET Framework 4.8 and Microsoft Edge WebView2 Runtime.
These are development builds. Update metadata uses a dedicated RSA/SHA-256 signing key; Windows Authenticode signing is not configured yet. Windows may show an unknown publisher. Diagnostics Service installation still requires an Authenticode-signed release.

Website: https://resotweak.app
